# Канал-спонсор через @MTProxybot

Работает только на **вашей** ноде с middle proxy и `ad_tag`. Shared-прокси из каталога чужого владельца спонсором не настроить покупателю без доступа к конфигу.

## Шаги

1. Откройте [@MTProxybot](https://t.me/MTProxybot) → `/newproxy`.
2. Отправьте `IP:PORT` ноды (часто `IP:443`).
3. Отправьте секрет **ровно 32 hex** (ключ пользователя) — **без** префикса `ee` и без домена.
4. Бот вернёт **tag** и свою ссылку. **Ссылку бота не используйте** — она часто нерабочая. Нужен только tag.
5. В telemt:
   ```toml
   [general]
   use_middle_proxy = true
   ad_tag = "tag_из_бота"
   ```
   Перезапустите сервис.
6. `/myproxies` → выберите сервер → **Set promotion** → публичная ссылка на канал (`https://t.me/name`). Приватный канал не примут.
7. Ждите до ~1 часа. Проверка — с аккаунта, который **не** подписан на канал.

## Клиентская ссылка

В Telegram отдавайте полный `ee`-секрет:

`ee` + 32 hex ключа + hex(ASCII домена FakeTLS)

Пример сборки: пакет `packages/mtproto`.
